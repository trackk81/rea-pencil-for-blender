# 배포 전 Blender 호환성 확인

사용자 요청(2026-11-11): 이후 변경은 기존 지원 버전과 공식 최신 안정 Blender에서도 검사한다.

- 공식 다운로드에서 최신 안정 버전을 확인하고 beta/alpha와 구분한다.
- 사용자 설정과 파일을 쓰지 않는 portable 환경에서 실제 설치 ZIP으로 검사한다.
- 애드온 등록, GPU 프리뷰 실제 draw, GPU 실패 후 Native 전환/선 생성, CPU 기본 선 렌더 및 GPU 렌더 회귀를 확인한다.
- 시험 코드의 옛 engine 이름 등 fixture 오류와 제품 오류를 구분한다. 실패/충돌 로그도 보존한다.
- 일부 렌더 성공이나 버전 검사 우회만으로 해당 버전 전체 지원을 선언하지 않는다.

0.28.18 확인 범위: Blender 4.4, 4.5.9. 최신 5.2.4에서는 CPU 기본 선 렌더 성공, 미리보기 버전 차단 및 GPU 회귀 중 충돌이 남음. 자세한 근거는 workspace artifacts/compat_blender52/RESULTS.md.
