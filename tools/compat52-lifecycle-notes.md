# Blender 5.2.4 애드온 재등록 검증

2026-11-11 KST. 공개 0.28.18은 REA 노드 트리가 있는 상태에서 두 번째 애드온 등록 중 충돌했다. Blender가 소켓 클래스를 등록하는 동안 트리의 업데이트를 호출했고, 기존 코드는 Scene 등록 여부보다 먼저 `self.nodes`를 조회했다. `lea_line/ui.py`에서 Scene 등록 여부를 먼저 확인하도록 순서를 바꿨다.

수정 후 격리 Blender 5.2.4와 4.4에서 등록·해제를 두 번 완료했다. 재등록 뒤 동일한 트리 이름, 노드 수, 링크 수와 테스트용 사용자 속성이 남아 있음을 확인했다. 두 버전 모두 재등록 중 RNA 클래스 경고가 출력됐으나 정상 종료했다. Blender 5.2.4의 독립 GPU 선 렌더 9회와 재등록을 포함한 회귀 항목 10개도 통과했다. Python 구문 검사와 diff 검사 통과.

재현 스크립트와 실행 로그는 작업공간 `artifacts/compat52_lifecycle_guard`에 있다. 이전 충돌 근거는 `artifacts/compat52_lifecycle`에 있다. 사용자 장면, 설치본 및 공개 릴리스는 보존했다.

Blender 5.2 미리보기 버전 검사와 Grease Pencil API 호환 검증이 남아 있다. 이번 검증 범위는 애드온 재등록과 기존 GPU 렌더 회귀다.
